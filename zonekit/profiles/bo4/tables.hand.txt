### f2e2c2e0
# RVA 0x2e2c2e0, `Load_StreamedData(flag, void** slot, XImage* owner)` - the streamed pixel /
# sound payload of whatever owns it.  The transcriber cannot express this one: which of three
# regions runs is decided by two bits of the OWNER's flag byte, and two of the three sit under
# DB_PushStreamPos(6)/(7), which are dead blocks (NOTES.txt section 1) that read nothing.
# Working the branch out by hand, with bVar1 = the owner's flags at +0x47:
#   (bVar1 & 3) == 0                 -> push(6), dead, reads nothing
#   bits 01 (bit0 set, bit1 clear)   -> push(7), dead, reads nothing
#   bits 10 or 11 (bit1 set)         -> falls through to the real read, in the caller's block
# so the payload is present exactly when bit 1 of the owner's flag byte is set.
# `%off` reaches the owning struct, which is what `param_3` is here.
SELF|0
IF|(u8@%0x47 & 2) != 0
BYTES+|0|u32@%0x40
ENDIF
